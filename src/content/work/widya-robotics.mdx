## Context & Problem

**Widya Robotics** builds industrial AI, computer vision, and automation products. As the product line expanded, the web presence needed to serve two audiences simultaneously:

1. **Enterprise buyers and partners** who need fast, clear, mobile-responsive product pages that communicate technical capability.
2. **Internal marketing and product teams** who need to publish case studies, announcements, and specification updates without waiting on engineering deploys.

## Architecture & Implementation

Working in Yogyakarta as a **Frontend Developer**, I engineered modular frontend features and standalone web projects using **Next.js**, **Strapi Headless CMS**, and **PostgreSQL**.

### 01 // Component-Driven Next.js Frontend
- Collaborated directly with the **UI/UX division** to translate Figma design systems into reusable, responsive React and Next.js components.
- Tuned layout responsiveness across desktop, tablet, and mobile viewports with clean typography and predictable spacing.

### 02 // Strapi CMS & PostgreSQL Content Modeling
- Structured relational content types in **Strapi CMS** backed by **PostgreSQL** so non-technical editors could compose product sections, media galleries, and news updates safely.
- Connected the Next.js frontend to Strapi's API layer with defensive fallbacks so pages remained resilient even when optional CMS fields were omitted.

### 03 // GitLab Team Workflow
- Managed feature branches, merge requests, and peer reviews through **GitLab**, coordinating releases between UI/UX designers and backend engineers.

## Key Outcomes & Takeaways

- **Faster publishing cycle:** Content updates moved from code commits to self-serve Strapi publishing.
- **Consistent UI quality:** Shared component primitives kept branding and responsiveness uniform across multiple web properties.
