## Context & Problem

Airline ticketing is a classic stress test for full-stack web engineering: users filter routes across dates and cabin classes, hold specific seats under time pressure, enter multi-passenger details, and expect an immediate, reliable e-ticket confirmation.

During the **SYNRGY Academy** intensive bootcamp (**Bank Central Asia × Binar Academy**), our cross-division squad was challenged to ship a complete **full-stack ticketing application** using the JavaScript ecosystem and **Agile Scrum**.

## Engineering & Scrum Execution

### 01 // Cross-Division Agile Scrum
- Worked in structured sprints alongside Frontend, Backend, UI/UX, and Quality Assurance teammates.
- Participated in sprint planning, daily standups, backlog grooming, and sprint retrospectives to keep API contracts and UI screens aligned.

### 02 // Multi-Step Booking & Seat Flow
- Built interactive flight search, multi-criteria filtering (schedule, price tier, airline, transit count), and passenger checkout steps.
- Handled asynchronous loading, form validation, and edge cases such as expired holds or unauthenticated redirects cleanly.

### 03 // REST API Integration & Verification
- Integrated authentication, booking creation, payment status transitions, and history retrieval against the squad's REST API backend.

## Key Outcomes & Takeaways

- **End-to-end delivery under deadline:** Shipped a working full-stack product from initial Figma wireframes and database ERD to live final presentation.
- **Production teamwork habits:** Built muscle memory for API contract negotiation, Git conflict resolution, and iterative QA feedback loops.
